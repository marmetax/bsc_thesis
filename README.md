# bsc_thesis
This theis presents the development of a Knowledge System (KS) which diagnoses Diabetes. First, in the beginning, there is an introduction to knowledge systems, emphasising in expert systems and tools used in their development. More emphasis is given on tools used for the development of this KS (DiaTheSDia). These tools are Prolog and HTML, the first has been used for the implementation of the reasoning engine and the knowledge base of the system, and the second is used for the implementation of the system’s interface. Then, there is an introduction to the Diabetes disease. Next, the design of the system along with its diagnostic method are presented. Then, the implementations of both the diagnostic system and the interface of DiaTheSDia are presented. In addition, sample sessions of the DiaTheSDia system illustrate its main functions. After that, the study of the performance of the system is discussed. Finally, the main part of the report ends by discussing conclusions and future extensions to this project.  There are four annexes. The first appendix presents the installation of appropriate supporting software to run this system. The second appendix presents the abbreviations of medical terms used in the system. The third appendix presents the Prolog code of this KS. In the last appendix,  the implementation of the representation of the Knowledge Base  in  Prolog is presented.

In order to run this code, you need to download and install SWI Prolog, update the save path fields as mentioned above. Then, run SWI Prolog, consult the main code and then run the **?-server(8000).** command. Afterwards, open any browser and visit **localhost:8000**.
